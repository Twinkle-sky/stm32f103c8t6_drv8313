# 开环点亮任务清单（DRV8313 + AS5600）

> 目标：**不改闭环逻辑，先让电机以开环电压矢量模式平稳转起来**，同时验证硬件、PWM、编码器三条链路，为后续闭环铺路。
>
> 依据：`hardware/SCH.pdf` 原理图 + `example/foc_example1`（同系列驱动板，引脚完全一致）。

---

## 0. 本板硬件要点（从原理图提取）

### 0.1 电源

| 电源 | 来源 | 说明 |
|---|---|---|
| 5V | Type-C USB 直接输入 | LED 亮为指示 |
| 12V（VM） | MT3608 升压（FB: 100k/5.1k，Vout ≈ 0.6×(1+100/5.1) ≈ 12.4V） | 供 DRV8313 VM，LED 为指示 |
| 3V3 | XC6206P332MR LDO（5V→3.3V） | MCU、AS5600、运放供电 |

⚠️ 板上 12V 由 USB 5V 升压而来，**堵转/大电流时 MT3608 会限流跌压**，若电机带载无力或板子重启，优先怀疑供电。

### 0.2 DRV8313（U6）控制引脚 —— 关键

| DRV8313 引脚 | 连接 | 含义 |
|---|---|---|
| IN1（pin 27） | **PA0**（TIM2_CH1） | U 相 PWM |
| IN2（pin 25） | **PA2**（TIM2_CH3） | V 相 PWM |
| IN3（pin 23） | **PA3**（TIM2_CH4） | W 相 PWM |
| EN1/EN2/EN3（26/24/22） | **并联到 PA7**（GPIO 输出） | 三相使能统一控制，高电平使能 |
| SLEEP#（17）/ RESET#（16） | 接 GND | 常使能、不复位，无需软件管理 |
| FAULT#（18） | 未接 MCU | 故障时无中断可查，靠观察电机行为 |
| OUT1/2/3 | 电机端子 M1-PORT-1/2/3 | 三相输出 |

⚠️ PA7 同时控制三相使能：**上电时 PA7 浮空前驱动未使能，这是安全的；但调试中一旦拉高 PA7，PWM 必须已配置为有效电平**，否则 MOS 全开短路。约定：上电默认 PA7 = 低（关断），PWM 就绪后再拉高。

### 0.3 电流采样（本次开环可暂不使用，但配置好备用）

- 3 路 **INA199A1**（增益 50V/V）+ 20mΩ 低边采样电阻（R17/R20/R23），REF 偏置 1.65V（零电流 = 1.65V）；
- 输出：OUT1 相 → **PA4**（ADC1_IN4），OUT2 相 → **PA5**（ADC1_IN5），OUT3 相 → **PA6**（ADC1_IN6）；
- 换算：`I = (V_ADC − 1.65) / 0.02 / 50`，满量程 ±1.65A。

### 0.4 位置传感器 AS5600

- **两个封装位（U4/U5）共用同一条 I2C1 总线**：PB6 = SCL，PB7 = SDA，地址固定 0x36 —— ⚠️ **只焊/只贴一颗磁编码器芯片**，两颗同时在位会地址冲突；
- DIR 引脚经 10kΩ 上拉 3V3（DIR=高），OUT/PGO 未接；
- I2C 必须用 **DMA 链式循环读取 + 错误回调重启**（参考 example1 `foc_as5600.c`），否则角度数据流会中断。

### 0.5 调试接口

| 接口 | 引脚 | 用途 |
|---|---|---|
| CN1 | USART1：PA9(TX)/PA10(RX) + 5V + GND | `printf` 调试，接 USB-TTL（**TX↔RX 交叉**） |
| CN2 | SWD：PA13(SWDIO)/PA14(SWCLK) + 3V3 + GND | ST-LINK 烧录 |
| LED1 | PC13 | 心跳/状态灯（低电平点亮） |
| BOOT0 | R7 10k 下拉 | 正常从 Flash 启动 |

## 1. 阶段一：硬件静态检查（上电前 15 分钟）

- [ ] 目视检查：焊点、短路的 0603 电阻、AS5600 只有一颗、磁铁已用双面胶/热熔胶固定在电机轴心且正对芯片中心；
- [ ] 电机三根线接入 M1-PORT-1/2/3（此时任意接相序，方向后面软件里调）；
- [ ] 不插电机、只插 Type-C：万用表量
  - 5V ≈ 5V（USB）；
  - 12V 轨 ≈ 12.3~12.4V（MT3608 输出，LED2 亮）；
  - 3V3 ≈ 3.3V；
- [ ] 量 AS5600 供电 3V3、I2C 线（PB6/PB7）被上拉到 3V3；
- [ ] **上电状态下量 DRV8313 的 IN1/IN2/IN3 引脚电压**（此时 MCU 未配置 PWM，应为确定电平，无抖动）——确认 PA7 初始为低、驱动未使能时电机不发热。

## 2. 阶段二：CubeMX 配置（firmware.ioc）

当前 `firmware.ioc` 只有 SWD + HSE + PC13 + SysTick，需补齐以下外设：

### 2.1 已确认无需改动的部分

- 时钟：HSE 8MHz × PLL9 = **SYSCLK 72MHz**（.ioc 已配好）✅

### 2.2 TIM2 → 三相 PWM（核心）

| 配置项 | 值 | 说明 |
|---|---|---|
| Clock Source | Internal | 72MHz |
| Prescaler | 0 | — |
| Counter Mode | **Center aligned mode 1** | 中心对齐 |
| Counter Period | **3600-1** | PWM 频率 = 72M/(2×3600) ≈ 10kHz |
| CH1（PA0） | PWM Generation CH1 | U 相 |
| CH3（PA2） | PWM Generation CH3 | V 相 |
| CH4（PA3） | PWM Generation CH4 | W 相 |
| CH2（PA1） | 本阶段不使能 | 预留作 ADC 触发 |
| 自动重装载预装载 | Enable | 占空比平滑更新 |

### 2.3 GPIO

| 引脚 | 配置 | 初始电平 |
|---|---|---|
| PA7 | GPIO_Output（推挽），标签 `MOTOR_EN` | **Low**（上电关断驱动） |
| PC13 | GPIO_Output，标签 `LED` | 已有 |

### 2.4 I2C1（AS5600）

| 配置项 | 值 |
|---|---|
| 模式 | I2C，Fast Mode 400kHz |
| PB6/PB7 | I2C1_SCL / I2C1_SDA（上拉已在板上） |
| DMA | I2C1_RX → DMA1 Channel7，Circular，优先级 High |
| 中断 | I2C1 event interrupt（DMA 回调依赖）+ error interrupt |

### 2.5 USART1（调试串口）

- 模式 Asynchronous，115200-8-N-1，PA9/PA10（板上 CN1 已引出）。

### 2.6 本阶段**不需要**配置（开环用不到）

- ADC（电流采样）——闭环阶段再加；
- TIM3 控制环中断——闭环阶段再加；
- 但 AS5600 的 I2C 建议本次就配好并用 DMA 读起来（验证传感器，也为闭环校准做准备）。

## 3. 阶段三：最小代码验证（按顺序，每步有验收标准）

在 `drivers/motor_ctrl/`（当前为空）下新建 `foc.c/h`、`foc_math.c/h`、`foc_as5600.c/h`，从 example1 移植：
- `foc_math.c/h`：`_sin_q10/_cos_q10` 正弦表、`_normalizeAngle`、`FOC_MulQ10` —— 零依赖，直接拷；
- `foc.c/h`：`FOC_VoltageOutput()` —— 把其中 `&htim2` 的三行 `__HAL_TIM_SET_COMPARE` 对准 TIM2 CH1/CH3/CH4；
- `foc_as5600.c/h`：I2C DMA 链式读 0x0C 寄存器 + 错误重启；
- `pid` 模块本次用不到，暂不移植。

### 步骤 3.1 —— LED + 串口通

- [ ] `app_init()` 里 PC13 闪烁（200ms），串口 1s 一条心跳。
- **验收**：LED 闪、串口出字。

### 步骤 3.2 —— AS5600 数据流

- [ ] 启动 DMA 链式读取，主循环 100ms 打印一次原始角度（0~4095）。
- **验收**：手转电机轴一圈，角度单调 0→4095→0 往返，无跳变卡死；记录"正转（你定义的正方向）时角度是增是减"，这就是将来的 `AS5600_DIR`（±1）。
- 若一直为 0 或打印 `i2c err`：查地址 0x36、接线、在错误回调里重启读取。

### 步骤 3.3 —— PWM 波形（电机不接）

- [ ] PA7 保持低，启动 TIM2 CH1/3/4，占空比设 50%；示波器/逻辑分析仪量 PA0/PA2/PA3。
- **验收**：10kHz 中心对齐（相邻周期相位对称），三相同占空比；示波器看 DRV8313 的 OUT1 对 GND 应无输出（EN 没开）。
- [ ] 拉高 PA7，此时三相对称 50%，OUT1/2/3 对地 ≈ 6V 直流（等效零矢量），电机应有轻微"上电锁定感"或不动的嗡声。
- **验收后立刻把 PA7 拉回低**。

### 步骤 3.4 —— 静态电压矢量 + 齿感测试（核心验证）

- [ ] 实现 `FOC_VoltageOutput(0, Uq, θ)`，固定 θ = 0、π/2、π、3π/2 四个角度，Uq 从 **0.5V 起步**（对应换算到你的占空比域，别超过 1~2V）。
- **验收**：每个角度转子被吸到一个固定位置并保持；用手指能感受到"档位感"（齿槽转矩）。依次换角度，转子位置步进 90°（电角度）。
- ⚠️ 若电机无反应：查 PA7 是否拉高、Uq 换算是否正确（`duty = Uq/Vm × 1024` 域）。
- ⚠️ 若电机猛转一下或异响：立即断电，查 PWM 频率与相序。

### 步骤 3.5 —— 开环旋转

- [ ] 在 TIM3 定时中断（先配 1kHz）里让 θ 匀速递增：`θ += ω_open × dt`，ω 从 **2 rad/s（电角度）起步**，Uq 固定 1~2V。
- [ ] θ 用 `float` 累加、输出前 `_normalizeAngle` 归一化到 0~2π。
- **验收**：电机以极低、均匀的速度旋转（可能伴随低速顿挫，正常）。逐步加大 ω 和 Uq，找到"平顺不啸叫"的最低组合。
- ⚠️ 顿挫严重/抖动大：ω 太低或 Uq 太小，加大；电机发热明显：Uq 太大，减小。
- [ ] 主循环 100ms 打印 `θ` 与实测 AS5600 角度差值——两者应同步变化（方向相反也没关系，记下符号）。

## 4. 阶段四：编译与烧录

1. `cmake --preset Debug` 配置（首次），然后 **先读 `build/Debug/CMakeCache.txt` 拿到真实工具链路径**（CubeMX 捆绑的工具链在 `%LOCALAPPDATA%/stm32cube/bundles/` 下：gnu-tools-for-stm32、cmake、ninja），把三个 bin 目录加进 PATH 再 `cmake --build build/Debug`；
2. 烧录前先 `STM32_Programmer_CLI -l` 确认 ST-LINK 在位（插 CN2 SWD，注意 3V3/GND 别接反），再 `-c port=SWD -w <elf> -v`；
3. 报 DEV_CONNECT_ERR：拔插 ST-LINK、确认板上 3V3 正常。

## 6. 常见问题速查

| 现象 | 原因 |
|---|---|
| 12V 偏低/板子重启 | MT3608 限流，USB 供电不足；换带供电能力的 USB 口 |
| 电机完全无反应 | PA7 没拉高；Uq 换算错；PWM 引脚复用没生效（量 PA0 有无波形） |
| 三相中一相不动 | 该相 IN 脚 PWM 没启动（PA0/PA2/PA3 逐一量） |
| 有齿感但换角度不动 | 角度没归一化 / 正弦表索引越界 |
| 低速剧烈顿挫 | 正常（开环六步本质），ω 加大后平滑 |
| AS5600 读数跳变 | 磁铁偏心；两颗芯片同时在位（地址冲突）；I2C 错误后未重启 DMA |
| 电机发烫 | Uq 太大、堵转时间过长；开环锁定阶段 Uq ≤ 2V、单次 ≤ 数秒 |

## 7. 完成后 → 闭环路线预告

开环验收通过后，闭环阶段要加的事：ADC1（IN4/IN5，TIM2 CH2 触发 + DMA）电流采样 → 零位校准（静态锁定读 AS5600）→ 速度环 PID（TIM3 200Hz）→ SVPWM 输出。对应教程见 `docs/STM32_FOC_开发教程.md` §3.3、§6.1。
